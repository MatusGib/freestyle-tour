# PWA Rider and Event Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A re-runnable tool, `npm run tour-data`, that reads pwaworldtour.com and commits a dataset of every PWA freestyle event 2006–2026 (entries, placings, points, ladders), riders under pseudonyms, and a Glicko-2 rating for each rider going into each event.

**Architecture:** Small pure modules in `lib/pwa/`: page parsers, rider matching, pseudonyms, Glicko-2 and the ratings run, each tested on its own. A cached, polite crawler and a collector walk the site; `tools/pwa.mjs` joins them and writes `tour/` only when every step has succeeded. Nothing in the game, mods or server changes.

**Tech Stack:** Node 22+ built-ins only (`fetch`, `node:test`, `node:fs`, `node:crypto`). No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-24-tour-data-design.md`

## Facts this plan relies on (verified 2026-10-24)

- Every module and test in this plan was run first as a prototype: all tests pass, and the prototype collected four real seasons (2008, 2012, 2016, 2025) from the live site. It found:
  - 13 freestyle events, 526 entries and 520 ladder heats, with every one of the 1,040 ladder sailors matched to an entry;
  - 116 pages downloaded, one per second;
  - a check of 63.9% on 101 heats in 2025. That run had nothing between 2016 and 2025, so most 2025 riders were rated as newcomers. The full history should do better, but the 65% bar is unproven until Task 10.
- The fixtures in `test/fixtures/pwa/` are trimmed copies of real pages, committed with this plan. They keep the site's exact markup.
- **Results pages:** a results page is an HTML fragment.
  - Its division tabs are links whose `href` contains `eventDiscipline` and a `cHash`.
  - Each row has `rank-no`, `rank-name` (a link holding the name), `rank-sail-number` and `rank-total-points` cells.
  - A page without results shows `<div class="no-entries-found-msg">`.
- **One-discipline events** (for example 2012 Podersdorf, men's freestyle only): the results page has no tabs and shows the table itself. The event page's "Disciplines" list names the discipline (`Men Freestyle`).
- **Default tab content:** the default results page of an event with tabs can show another division's table under the active tab's label. For example, 2008 Sotavento shows slalom riders under "Freestyle Men". So the collector always reads each freestyle tab's own URL.
- **Ladders:** the ladder XML sits in a script as `` ladderXml = `…`; ``.
  - 2025 ladders give the winner place 1 and the loser 0. 2014 ladders give 1 and 2, and have no `<discipline>` and no `<heatId>`.
  - Unsailed heats have empty names and places, written as `<x/>` (2025) or `<x></x>` (2014).
- **Server errors:** some results pages answer 500 every time: the 2025 Margaret River Wave Classic, and two 2008 slalom events. The collector skips such pages with a note instead of stopping.
- **Data quirks:**
  - Ladders have typos (`Wieczzorek` for Wieczorek) and cut-off sail numbers (`Sugi J-`).
  - Names carry nicknames in quotes or brackets (`Jose "Gollito" Estredo`, `Elton (Taty) Frans`).
  - Some text is HTML-encoded twice (`Alaçat&amp;#305;`).
- The site accepts the User-Agent `freestyle-tour-data/1.0 (private, non-commercial)`.

```js
// Parsers for the PWA World Tour pages the data tool reads. Each takes a page's
// text and returns plain data. They throw, saying what was missing, when a page
// doesn't have the expected shape; the caller adds the URL.

const ENTITIES = { amp: "&", quot: '"', apos: "'", lt: "<", gt: ">", nbsp: " " };

// Decodes until nothing changes, because some pages encode twice
// ("Alaçat&amp;#305;").
export function decodeHtml(text) {
  const decoded = text.replace(/&(#x[0-9a-f]+|#\d+|[a-z]+);/gi, (match, code) => {
    if (code[0] !== "#") return ENTITIES[code.toLowerCase()] ?? match;
    return String.fromCodePoint(code[1].toLowerCase() === "x" ? parseInt(code.slice(2), 16) : Number(code.slice(1)));
  });
  return decoded === text ? text : decodeHtml(decoded);
}

// Text without tags or entities, with runs of white space as one space.
const clean = (html) => decodeHtml(html.replace(/<[^>]*>/g, " ")).replace(/\s+/g, " ").trim();

const NO_ENTRIES = 'class="no-entries-found-msg"';

// The event pages a season listing links to, as slugs.
export function parseSeason(html) {
  return [...new Set([...html.matchAll(/class="event-calendar-link" href="\/events\/detail\/([^"/]+)\/"/g)].map((m) => m[1]))];
}

const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];

// "Jul 18 - Jul 27 2025" as ISO dates. The year belongs to the end date, so a
// start month later than the end month is in the year before.
export function parseDates(text) {
  const m = text.match(/^([A-Z][a-z]{2}) (\d{1,2})(?: - ([A-Z][a-z]{2}) (\d{1,2}))? (\d{4})$/);
  const [startMonth, endMonth] = m ? [MONTHS.indexOf(m[1]), MONTHS.indexOf(m[3] ?? m[1])] : [-1, -1];
  if (startMonth < 0 || endMonth < 0) throw new Error(`unreadable dates "${text}"`);
  const year = Number(m[5]);
  const iso = (y, month, day) => `${y}-${String(month + 1).padStart(2, "0")}-${day.padStart(2, "0")}`;
  return { start: iso(startMonth > endMonth ? year - 1 : year, startMonth, m[2]), end: iso(year, endMonth, m[4] ?? m[2]) };
}

export function parseEvent(html) {
  const name = html.match(/<h1>([\s\S]*?)<\/h1>/);
  const date = html.match(/<span class="date">\s*<span class="label">Date: <\/span>([\s\S]*?)<\/span>/);
  if (!name) throw new Error("missing the event name (<h1>)");
  if (!date) throw new Error("missing the event dates");
  const location = html.match(/<span class="event-location"><span class="label">Location: <\/span>([\s\S]*?)<\/span>/);
  const disciplines = html.match(/<span class="event-disciplines"><span class="label">Disciplines: <\/span>([\s\S]*?)<\/span>/);
  const results = html.match(/href="(\/events\/results\/results\/(\d+)\?type=24)"/);
  const ladders = html.match(/href="(\/events\/elimination-ladder\/elimination-ladders\/\d+\?type=25)"/);
  return {
    id: results ? Number(results[2]) : null,
    name: clean(name[1]),
    ...parseDates(clean(date[1])),
    location: location ? clean(location[1]) : "",
    disciplines: disciplines ? disciplines[1].split(",").map(clean).filter(Boolean) : [],
    resultsUrl: results?.[1] ?? null,
    laddersUrl: ladders?.[1] ?? null,
  };
}

// The division tabs of a results page: [{ label, url }].
export function parseResultTabs(html) {
  return [...html.matchAll(/<a class="get-from-ajax[^"]*" href="([^"]*eventDiscipline[^"]*)">([\s\S]*?)<\/a>/g)].map((m) => ({ label: clean(m[2]), url: decodeHtml(m[1]) }));
}

// The entries of the division a results page shows, or [] when it has none.
export function parseResults(html) {
  if (html.includes(NO_ENTRIES)) return [];
  const table = html.match(/<table>([\s\S]*?)<\/table>/);
  if (!table) throw new Error("missing the results table");
  return table[1].split("<tr>").filter((row) => row.includes('class="rank-no"')).map((row) => {
    const cell = (cls) => {
      const m = row.match(new RegExp(`<(td|div) class="${cls}">([\\s\\S]*?)</\\1>`));
      if (!m) throw new Error(`a results row is missing ${cls}`);
      return clean(m[2]);
    };
    return { place: Number(cell("rank-no")) || 0, name: cell("rank-name"), sailNumber: cell("rank-sail-number"), points: Number(cell("rank-total-points")) || 0 };
  });
}

// Some old results list every place as 0. Their places then come from the
// points, highest first, with equal points sharing a place.
export function placesFromPoints(entries) {
  const sorted = [...entries].sort((a, b) => b.points - a.points);
  return sorted.map((entry) => ({ ...entry, place: 1 + sorted.filter((other) => other.points > entry.points).length }));
}
```

```js
// The ladders a ladder index links to: [{ title, url }].
export function parseLadderIndex(html) {
  if (html.includes(NO_ENTRIES)) return [];
  return [...html.matchAll(/<a class="get-from-ajax[^"]*" href="([^"]*eliminationLadder[^"]*)">([\s\S]*?)<\/a>/g)].map((m) => ({ title: clean(m[2]), url: decodeHtml(m[1]) }));
}

// An element's text, "" when empty (<x/> or <x></x>), null when absent.
function tag(xml, name) {
  const m = xml.match(new RegExp(`<${name}>([\\s\\S]*?)</${name}>|<${name}/>`));
  return m ? decodeHtml(m[1] ?? "").trim() : null;
}

// The ladder in a ladder page's XML. Only heats that were sailed are kept: at
// least two named sailors, each with a place. The XML of older seasons has no
// <discipline>, so discipline is then null.
export function parseLadder(html) {
  const xml = html.match(/ladderXml = `([\s\S]*?)`;/)?.[1];
  if (!xml) throw new Error("missing the ladder XML (ladderXml)");
  const title = tag(xml, "name");
  const sex = tag(xml, "sex");
  if (!title || !sex) throw new Error("the ladder XML has no name or sex");
  const rounds = [...xml.matchAll(/<round>([\s\S]*?)<\/round>/g)].map((round) => [...round[1].matchAll(/<heat>([\s\S]*?)<\/heat>/g)]
    .map((heat) => ({
      heat: tag(heat[1], "heatName"),
      sailors: [...heat[1].matchAll(/<sailor>([\s\S]*?)<\/sailor>/g)]
        .map((s) => ({ surname: tag(s[1], "sailorName"), sailNumber: tag(s[1], "sailNr"), place: tag(s[1], "place") }))
        .filter((s) => s.surname),
    }))
    .filter((heat) => heat.sailors.length >= 2 && heat.sailors.every((s) => s.place !== ""))
    .map((heat) => ({ ...heat, sailors: heat.sailors.map((s) => ({ ...s, place: Number(s.place) })) })));
  return { title, sex, discipline: tag(xml, "discipline"), double: /\(double\)$/.test(title), rounds };
}
```

```js
// Who is who across events: name keys and rider ids, matching ladder sailors
// to entries, heat ranks, and a list of possible duplicates for a person to check.

// Plain comparison, so the order never depends on the machine's locale.
export const byText = (a, b) => (a < b ? -1 : a > b ? 1 : 0);

const LETTERS = { ø: "o", ß: "ss", æ: "ae", œ: "oe", đ: "d", ł: "l", ı: "i" };

// Nicknames in a name: "Gollito" in quotes, (Taty) in brackets.
export const NICKNAME = /["“”][^"“”]*["“”]|\([^)]*\)/g;

// A name without nicknames, accents or case, words joined by "-":
// Jose "Gollito" Estredo → jose-estredo.
export function nameKey(name) {
  return name
    .replace(NICKNAME, " ")
    .normalize("NFD")
    .replace(/\p{M}/gu, "")
    .toLowerCase()
    .replace(/[øßæœđłı]/g, (c) => LETTERS[c])
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-|-$/g, "");
}

export const DIVISION_LETTERS = { men: "m", women: "w" };

export function riderId(division, name, aliases = {}) {
  const id = `${DIVISION_LETTERS[division]}:${nameKey(name)}`;
  return aliases[id] ?? id;
}

const sailKey = (sail) => sail.toUpperCase().replace(/\s+/g, "");

// True when b is a with at most one letter added, dropped or changed.
export function withinOneEdit(a, b) {
  if (Math.abs(a.length - b.length) > 1) return false;
  let i = 0;
  while (i < a.length && i < b.length && a[i] === b[i]) i += 1;
  if (a.length === b.length) return a.slice(i + 1) === b.slice(i + 1);
  return a.length > b.length ? a.slice(i + 1) === b.slice(i) : a.slice(i) === b.slice(i + 1);
}

// The entry a ladder sailor is: the only one with their sail number, else the
// only one with their surname. A surname of five letters or more may be one
// letter off (ladders have typos). Two entries with the surname are told apart
// by a cut-off sail number ("J-" for "J-7"). null when nothing is unique.
export function matchSailor(sailor, entries) {
  const sail = sailor.sailNumber ? sailKey(sailor.sailNumber) : "";
  const bySail = entries.filter((e) => sail && sailKey(e.sailNumber) === sail);
  if (bySail.length === 1) return bySail[0];
  const surname = nameKey(sailor.surname);
  const words = surname.split("-").length;
  const tail = (e) => nameKey(e.name).split("-").slice(-words).join("-");
  let bySurname = entries.filter((e) => tail(e) === surname);
  if (!bySurname.length && surname.length >= 5) bySurname = entries.filter((e) => withinOneEdit(tail(e), surname));
  if (bySurname.length > 1 && sail) bySurname = bySurname.filter((e) => sailKey(e.sailNumber).startsWith(sail));
  return bySurname.length === 1 ? bySurname[0] : null;
}

// A heat's ranks from its published places: positive places rank the sailors
// (1 is best), 0 comes after every positive place, and equal places tie.
export function heatRanks(places) {
  const order = (place) => (place > 0 ? place : Infinity);
  return places.map((place) => 1 + places.filter((other) => order(other) < order(place)).length);
}

const byDate = (a, b) => byText(a.start, b.start) || a.id - b.id;

// Gives every entry a rider id and every ladder sailor the id of their entry.
// Returns the events in date order, the riders by id, and the ladder sailors
// that matched no entry (kept in their heat as { surname, sailNumber }).
export function resolveEvents(rawEvents, aliases = {}) {
  const riders = new Map();
  const unmatched = [];
  const events = [...rawEvents].sort(byDate).map((event) => {
    const divisions = {};
    for (const [division, { entries, ladders }] of Object.entries(event.divisions)) {
      const ids = new Set();
      const resolved = entries.map((entry) => {
        const id = riderId(division, entry.name, aliases);
        if (ids.has(id)) throw new Error(`${event.name}: two ${division} entries are ${id}`);
        ids.add(id);
        const rider = riders.get(id) ?? { id, division, name: entry.name, sailNumbers: [] };
        rider.name = entry.name; // events run oldest first, so this ends as the newest spelling
        rider.sailNumbers = [entry.sailNumber, ...rider.sailNumbers.filter((s) => s !== entry.sailNumber)].filter(Boolean);
        riders.set(id, rider);
        return { rider: id, name: entry.name, sailNumber: entry.sailNumber, place: entry.place, points: entry.points };
      });
      resolved.sort((a, b) => a.place - b.place || byText(a.name, b.name));
      divisions[division] = {
        entries: resolved,
        ladders: ladders.map((ladder) => ({
          title: ladder.title,
          double: ladder.double,
          rounds: ladder.rounds.map((round) => round.map(({ heat, sailors }) => ({
            heat,
            riders: sailors.map((sailor) => {
              const entry = matchSailor(sailor, resolved);
              if (entry) return entry.rider;
              unmatched.push({ event: event.id, division, heat, surname: sailor.surname, sailNumber: sailor.sailNumber });
              return { surname: sailor.surname, sailNumber: sailor.sailNumber };
            }),
            ranks: heatRanks(sailors.map((s) => s.place)),
          }))),
        })),
      };
    }
    return { ...event, divisions };
  });
  return { events, riders: [...riders.values()].sort((a, b) => byText(a.id, b.id)), unmatched };
}

// Pairs of ids that may be one person: one sail number under two ids within
// two seasons, or the same surname and first initial in a division.
export function possibleDuplicates(events, riders) {
  const pairs = new Map();
  const add = (a, b, reason) => {
    const [x, y] = [a, b].sort(byText);
    if (x !== y && !pairs.has(`${x} ${y}`)) pairs.set(`${x} ${y}`, { a: x, b: y, reason });
  };
  const sails = new Map();
  for (const event of events) {
    for (const [division, { entries }] of Object.entries(event.divisions)) {
      for (const entry of entries) {
        if (!/\d/.test(entry.sailNumber)) continue;
        const key = `${division} ${sailKey(entry.sailNumber)}`;
        const uses = sails.get(key) ?? [];
        for (const use of uses) if (Math.abs(use.season - event.season) <= 2) add(use.rider, entry.rider, `sail number ${entry.sailNumber}`);
        uses.push({ rider: entry.rider, season: event.season });
        sails.set(key, uses);
      }
    }
  }
  const names = new Map();
  for (const rider of riders) {
    const words = nameKey(rider.name).split("-");
    if (words.length < 2) continue;
    const key = `${rider.division} ${words.at(-1)} ${words[0][0]}`;
    for (const other of names.get(key) ?? []) add(other, rider.id, "same surname and first initial");
    names.set(key, [...(names.get(key) ?? []), rider.id]);
  }
  return [...pairs.values()].sort((p, q) => byText(p.a, q.a) || byText(p.b, q.b));
}
```

```js
// Recognisable but changed names: one letter changes in the first name and one
// in the surname, so Balz Müller becomes Balt Möller.
import { NICKNAME, nameKey } from "./riders.mjs";

// The first name's last letter that is in this table changes.
const FIRST = { z: "t", t: "d", d: "t", s: "z", n: "m", m: "n", r: "l", l: "r", k: "c", c: "k", x: "s", b: "p", p: "b", g: "k", f: "v", v: "f", j: "y", w: "v", y: "i", a: "o", o: "a", e: "a", i: "y", u: "o" };
// The surname's first vowel changes.
const VOWEL = { a: "e", e: "a", i: "y", o: "u", u: "o", y: "i", ä: "e", ö: "ü", ü: "ö", á: "e", é: "a", í: "y", ó: "u", ú: "o" };

// Positions in word of the letters table can change, in reading order.
const changeable = (word, table) => [...word].flatMap((letter, i) => (letter.toLowerCase() in table ? [i] : []));

// word with the letter at i changed through table, keeping its case.
function swap(word, i, table) {
  const letters = [...word];
  const lower = letters[i].toLowerCase();
  letters[i] = letters[i] === lower ? table[lower] : table[lower].toUpperCase();
  return letters.join("");
}

// The pseudonyms to try for a name, best first: the first name's last
// changeable letter with the surname's first vowel, then the surname's second
// vowel, then the first name's next-to-last letter, then both. Nicknames are
// dropped; a one-word name only gets the surname change.
export function candidates(name) {
  const words = name.normalize("NFC").replace(NICKNAME, " ").trim().split(/\s+/);
  const last = words.length - 1;
  const surnames = changeable(words[last], VOWEL).slice(0, 2).map((i) => swap(words[last], i, VOWEL));
  const lasts = surnames.length ? surnames : [words[last]];
  if (!last) return lasts.filter((n) => n !== words[0]);
  const firstNames = changeable(words[0], FIRST).reverse().slice(0, 2).map((i) => swap(words[0], i, FIRST));
  const firsts = firstNames.length ? firstNames : [words[0]];
  const names = [[0, 0], [0, 1], [1, 0], [1, 1]]
    .filter(([f, l]) => f < firsts.length && l < lasts.length)
    .map(([f, l]) => [firsts[f], ...words.slice(1, last), lasts[l]].join(" "));
  return [...new Set(names)].filter((n) => n !== words.join(" "));
}

// A pseudonym for every rider (riders in id order): their hand fix, or the
// first candidate that is neither another rider's pseudonym nor any rider's
// real name. Returns a Map from rider id to pseudonym.
export function assignPseudonyms(riders, fixes = {}) {
  const ids = new Set(riders.map((r) => r.id));
  for (const id of Object.keys(fixes)) if (!ids.has(id)) throw new Error(`tour/pseudonyms.json names ${id}, who is not a rider`);
  const realNames = new Map(riders.map((r) => [nameKey(r.name), r.id]));
  const taken = new Map();
  const pseudonyms = new Map();
  // The rider a pseudonym would clash with, or null.
  const clash = (rider, name) => {
    const key = nameKey(name);
    const holder = taken.get(key);
    return holder && holder !== rider.id ? holder : realNames.get(key) ?? null;
  };
  const claim = (rider, name) => {
    taken.set(nameKey(name), rider.id);
    pseudonyms.set(rider.id, name);
  };
  for (const rider of riders) {
    if (!fixes[rider.id]) continue;
    const other = clash(rider, fixes[rider.id]);
    if (other) throw new Error(`the pseudonym fix for ${rider.id} (${fixes[rider.id]}) clashes with ${other}`);
    claim(rider, fixes[rider.id]);
  }
  for (const rider of riders) {
    if (pseudonyms.has(rider.id)) continue;
    const options = candidates(rider.name);
    const free = options.find((name) => !clash(rider, name));
    if (!free) {
      const tried = options.map((name) => `${name} (${clash(rider, name)})`).join(", ") || "none";
      throw new Error(`no free pseudonym for ${rider.id} (${rider.name}); tried ${tried}. Add one to tour/pseudonyms.json`);
    }
    claim(rider, free);
  }
  return pseudonyms;
}
```

```js
// Glicko-2 (Glickman, "Example of the Glicko-2 system", 2012), with weighted
// games. A rider is { rating, rd, volatility } on the usual 1500 scale.

const SCALE = 173.7178;
export const MAX_RD = 350;
const EPSILON = 0.000001;

const g = (phi) => 1 / Math.sqrt(1 + (3 * phi * phi) / (Math.PI * Math.PI));
const expected = (mu, muj, phij) => 1 / (1 + Math.exp(-g(phij) * (mu - muj)));
const toMu = (rating) => (rating - 1500) / SCALE;

export const newRider = (rating) => ({ rating, rd: MAX_RD, volatility: 0.06 });

// The rider after one rating period. games: [{ opponent, score, weight }],
// with the opponent's rating going into the period and score 1, 0.5 or 0.
// With no games only the deviation grows.
export function ratePeriod(rider, games, tau) {
  const mu = toMu(rider.rating);
  const phi = rider.rd / SCALE;
  const sigma = rider.volatility;
  if (!games.length) return { ...rider, rd: Math.min(MAX_RD, Math.sqrt(phi * phi + sigma * sigma) * SCALE) };

  let vInverse = 0;
  let sum = 0;
  for (const { opponent, score, weight = 1 } of games) {
    const muj = toMu(opponent.rating);
    const phij = opponent.rd / SCALE;
    const e = expected(mu, muj, phij);
    vInverse += weight * g(phij) ** 2 * e * (1 - e);
    sum += weight * g(phij) * (score - e);
  }
  const v = 1 / vInverse;
  const delta = v * sum;

  // The new volatility, by the Illinois algorithm (step 5 of the paper).
  const a = Math.log(sigma * sigma);
  const f = (x) => {
    const ex = Math.exp(x);
    return (ex * (delta * delta - phi * phi - v - ex)) / (2 * (phi * phi + v + ex) ** 2) - (x - a) / (tau * tau);
  };
  let A = a;
  let B;
  if (delta * delta > phi * phi + v) B = Math.log(delta * delta - phi * phi - v);
  else {
    let k = 1;
    while (f(a - k * tau) < 0) k += 1;
    B = a - k * tau;
  }
  let fA = f(A);
  let fB = f(B);
  while (Math.abs(B - A) > EPSILON) {
    const C = A + ((A - B) * fA) / (fB - fA);
    const fC = f(C);
    if (fC * fB < 0) {
      A = B;
      fA = fB;
    } else fA /= 2;
    B = C;
    fB = fC;
  }
  const volatility = Math.exp(A / 2);

  const phiStar = Math.sqrt(phi * phi + volatility * volatility);
  const phiNew = 1 / Math.sqrt(1 / (phiStar * phiStar) + 1 / v);
  const muNew = mu + phiNew * phiNew * sum;
  return { rating: 1500 + SCALE * muNew, rd: Math.min(MAX_RD, SCALE * phiNew), volatility };
}

// The chance that a beats b, counting both riders' deviations.
export function winChance(a, b) {
  const phi = Math.hypot(a.rd, b.rd) / SCALE;
  return 1 / (1 + Math.exp(-g(phi) * (toMu(a.rating) - toMu(b.rating))));
}
```

```js
// Glicko-2 ratings over the events in date order, each event one rating period
// per division. Gives each rider's rating going into every event they entered,
// and how well those ratings predicted ladder heats.
import { newRider, ratePeriod, winChance } from "./glicko.mjs";
import { byText } from "./riders.mjs";

export const TUNING = { tau: [0.3, 0.5, 0.75, 1.0], newcomerRating: [1300, 1400, 1500], placingsWeight: [2, 4, 6] };
export const TUNE_SEASONS = [2014, 2021];
export const CHECK_SEASONS = [2022, 2026];
export const BAR = 0.65;

// Who beat whom in one division of an event: [{ winner, loser, weight, heat }].
// Ladder heats give games of weight 1, leaving out heats with an unmatched
// sailor. Without any, the final places give a game for every pair with
// different places, weighted so each rider's event counts like placingsWeight heats.
export function gamesFor(division, placingsWeight) {
  const games = [];
  for (const ladder of division.ladders) {
    for (const round of ladder.rounds) {
      for (const { riders, ranks } of round) {
        if (riders.some((r) => typeof r !== "string")) continue;
        riders.forEach((winner, i) => riders.forEach((loser, j) => {
          if (ranks[i] < ranks[j]) games.push({ winner, loser, weight: 1, heat: true });
        }));
      }
    }
  }
  if (games.length) return games;
  const { entries } = division;
  const weight = placingsWeight / (entries.length - 1);
  for (const a of entries) for (const b of entries) if (a.place < b.place) games.push({ winner: a.rider, loser: b.rider, weight, heat: false });
  return games;
}

// Runs the periods. events must be in date order (as resolveEvents returns
// them). Returns before[eventId][division] as a Map from rider id to rating,
// and one prediction per ladder game: the chance its winner was given.
export function runRatings(events, { tau, newcomerRating, placingsWeight }) {
  const current = { men: new Map(), women: new Map() };
  const before = {};
  const predictions = [];
  for (const event of events) {
    before[event.id] = {};
    for (const [name, division] of Object.entries(event.divisions)) {
      const ratings = current[name];
      const entering = new Map(division.entries.map((e) => [e.rider, ratings.get(e.rider) ?? newRider(newcomerRating)]));
      before[event.id][name] = entering;
      const played = new Map([...entering.keys()].map((id) => [id, []]));
      for (const game of gamesFor(division, placingsWeight)) {
        const winner = entering.get(game.winner);
        const loser = entering.get(game.loser);
        if (game.heat) predictions.push({ season: event.season, p: winChance(winner, loser) });
        played.get(game.winner).push({ opponent: loser, score: 1, weight: game.weight });
        played.get(game.loser).push({ opponent: winner, score: 0, weight: game.weight });
      }
      for (const [id, rider] of ratings) if (!entering.has(id)) ratings.set(id, ratePeriod(rider, [], tau));
      for (const [id, rider] of entering) ratings.set(id, ratePeriod(rider, played.get(id), tau));
    }
  }
  return { before, predictions };
}

// The predictions of the seasons from–to: how many, the share the favourite
// won (an even chance counts as half), and the mean log loss.
export function scorePredictions(predictions, [from, to]) {
  const chosen = predictions.filter((p) => p.season >= from && p.season <= to);
  if (!chosen.length) return { heats: 0, hitRate: 0, logLoss: 0 };
  const hits = chosen.reduce((sum, { p }) => sum + (p > 0.5 ? 1 : p === 0.5 ? 0.5 : 0), 0);
  const loss = chosen.reduce((sum, { p }) => sum - Math.log(p), 0);
  return { heats: chosen.length, hitRate: hits / chosen.length, logLoss: loss / chosen.length };
}

// The settings with the lowest log loss on the tuning seasons; ties go to the
// first in TUNING order.
export function tune(events) {
  let best = null;
  for (const tau of TUNING.tau) {
    for (const newcomerRating of TUNING.newcomerRating) {
      for (const placingsWeight of TUNING.placingsWeight) {
        const settings = { tau, newcomerRating, placingsWeight };
        const { logLoss } = scorePredictions(runRatings(events, settings).predictions, TUNE_SEASONS);
        if (!best || logLoss < best.logLoss) best = { settings, logLoss };
      }
    }
  }
  return best.settings;
}

const round = (value, digits) => Number(value.toFixed(digits));

// What goes into tour/ratings.json.
export function buildRatings(events) {
  const settings = tune(events);
  const { before, predictions } = runRatings(events, settings);
  const check = scorePredictions(predictions, CHECK_SEASONS);
  const out = {};
  for (const [eventId, divisions] of Object.entries(before)) {
    out[eventId] = {};
    for (const [name, ratings] of Object.entries(divisions)) {
      const ids = [...ratings.keys()].sort(byText);
      out[eventId][name] = Object.fromEntries(ids.map((id) => {
        const r = ratings.get(id);
        return [id, { rating: round(r.rating, 2), rd: round(r.rd, 2), volatility: round(r.volatility, 6) }];
      }));
    }
  }
  return { settings, check: { heats: check.heats, hitRate: round(check.hitRate, 4), logLoss: round(check.logLoss, 4) }, events: out };
}
```

```js
// Fetches PWA pages one at a time, at least gapMs apart, and keeps each one in
// cacheDir. Later runs, and a crawl that stopped halfway, read the cache
// instead of downloading again.
import { createHash } from "node:crypto";
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";

export const USER_AGENT = "freestyle-tour-data/1.0 (private, non-commercial)";

export async function fetchText(url) {
  const res = await fetch(url, { headers: { "User-Agent": USER_AGENT } });
  return { status: res.status, text: await res.text() };
}

const fileFor = (url) => `${createHash("sha256").update(url).digest("hex").slice(0, 32)}.html`;
const pause = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

// get(url, { fresh }) resolves to the page's text. fresh downloads it again,
// once per run, even when it is cached. offline never downloads. A status
// other than 200 rejects with an error carrying that status.
export function createCrawler({ cacheDir, offline = false, fetch = fetchText, gapMs = 1000, now = Date.now, sleep = pause }) {
  let last = -Infinity;
  let downloads = 0;
  const fetched = new Set();
  return {
    get downloads() {
      return downloads;
    },
    async get(url, { fresh = false } = {}) {
      const file = join(cacheDir, fileFor(url));
      if ((!fresh || fetched.has(url)) && existsSync(file)) return readFileSync(file, "utf8");
      if (offline) throw new Error(`${url} is not in the cache, and --offline never downloads`);
      const wait = last + gapMs - now();
      if (wait > 0) await sleep(wait);
      last = now();
      const { status, text } = await fetch(url);
      downloads += 1;
      if (status !== 200) throw Object.assign(new Error(`${url} answered ${status}`), { status });
      mkdirSync(cacheDir, { recursive: true });
      writeFileSync(file, text);
      fetched.add(url);
      return text;
    },
  };
}
```

```js
// Reads the PWA site through a crawler into raw events: every event with
// freestyle results, its entries and its freestyle ladders, as the pages give
// them. Also returns notes for the summary.
import { parseEvent, parseLadder, parseLadderIndex, parseResultTabs, parseResults, parseSeason, placesFromPoints } from "./parse.mjs";

export const BASE = "https://www.pwaworldtour.com";
export const FIRST_SEASON = 2006;
export const LAST_SEASON = 2026;
const TABS = { "Freestyle Men": "men", "Freestyle Women": "women" };
// An event with one discipline has no tabs; its event page names the discipline.
const DISCIPLINES = { "Men Freestyle": "men", "Women Freestyle": "women" };
const SEXES = { male: "men", female: "women" };
const isFreestyle = (title) => /freestyle/i.test(title) && !/foil/i.test(title);

// refresh is a season, "all" or null; its pages are downloaded again.
export async function collect(crawler, { seasons, refresh = null, log = () => {} }) {
  const events = [];
  const notes = [];
  const ids = new Set();
  for (const season of seasons) {
    const fresh = refresh === "all" || refresh === season;
    const read = async (path, parse) => {
      const url = new URL(path, BASE).href;
      const text = await crawler.get(url, { fresh });
      try {
        return parse(text);
      } catch (error) {
        throw new Error(`${url}: ${error.message}`);
      }
    };
    // Like read, but an HTTP error is noted and gives null. Errors aren't
    // cached, so the next run tries the page again.
    const readIfThere = async (path, parse) => {
      try {
        return await read(path, parse);
      } catch (error) {
        if (!error.status) throw error;
        notes.push(`${new URL(path, BASE).href} answered ${error.status}, skipped`);
        return null;
      }
    };
    let found = 0;
    for (const slug of await read(`/events/${season}/`, parseSeason)) {
      const event = await read(`/events/detail/${slug}/`, parseEvent);
      if (!event.resultsUrl || ids.has(event.id)) continue;
      const tabs = await readIfThere(event.resultsUrl, parseResultTabs);
      if (!tabs) continue;
      const sources = tabs.filter((tab) => TABS[tab.label]).map((tab) => ({ division: TABS[tab.label], url: tab.url }));
      const only = event.disciplines.length === 1 && DISCIPLINES[event.disciplines[0]];
      if (!tabs.length && only) sources.push({ division: only, url: event.resultsUrl });
      if (!sources.length) continue;
      const divisions = {};
      for (const { division, url } of sources) {
        let entries = await readIfThere(url, parseResults);
        if (!entries?.length) {
          if (entries) notes.push(`${event.name}: no ${division}'s results`);
          continue;
        }
        if (entries.every((e) => e.place === 0)) {
          entries = placesFromPoints(entries);
          notes.push(`${event.name}: ${division}'s places taken from points`);
        }
        divisions[division] = { entries, ladders: [] };
      }
      if (!Object.keys(divisions).length) continue;
      if (event.laddersUrl) {
        const links = (await readIfThere(event.laddersUrl, parseLadderIndex)) ?? [];
        const ladders = [];
        for (const link of links.filter((l) => isFreestyle(l.title))) {
          const ladder = await readIfThere(link.url, parseLadder);
          if (ladder) ladders.push(ladder);
        }
        // An index without links may hold its one ladder itself.
        if (!links.length) {
          const embedded = await read(event.laddersUrl, (text) => (text.includes("ladderXml = `") ? parseLadder(text) : null));
          if (embedded) ladders.push(embedded);
        }
        for (const ladder of ladders) {
          if (ladder.discipline ? ladder.discipline !== "freestyle" : !isFreestyle(ladder.title)) continue;
          const rounds = ladder.rounds.filter((round) => round.length);
          const division = divisions[SEXES[ladder.sex]];
          if (division && rounds.length) division.ladders.push({ title: ladder.title, double: ladder.double, rounds });
        }
      }
      ids.add(event.id);
      events.push({ season, id: event.id, slug, name: event.name, start: event.start, end: event.end, location: event.location, divisions });
      found += 1;
    }
    log(`${season}: ${found} freestyle events`);
  }
  return { events, notes };
}
```

```js
// The files under tour/ that the data tool builds, as { path: text }.

const json = (value) => `${JSON.stringify(value, null, 2)}\n`;

// events: resolved events in date order; riders: by id; pseudonyms: Map from
// rider id; ratings: what buildRatings returns.
export function tourFiles({ events, riders, pseudonyms, ratings }) {
  const seasons = new Map();
  for (const { season, ...event } of events) seasons.set(season, [...(seasons.get(season) ?? []), event]);
  const files = {};
  for (const season of [...seasons.keys()].sort((a, b) => a - b)) files[`seasons/${season}.json`] = json({ season, events: seasons.get(season) });
  files["riders.json"] = json(riders.map((r) => ({ id: r.id, division: r.division, name: r.name, pseudonym: pseudonyms.get(r.id), sailNumbers: r.sailNumbers })));
  files["ratings.json"] = json(ratings);
  return files;
}
```

```js
// Builds tour/ from the PWA World Tour site: every freestyle event 2006–2026
// with its entries and ladders, riders under pseudonyms, and a Glicko-2 rating
// for each rider going into each event. Pages are cached in cache/pwa/.
//   npm run tour-data -- [--refresh <season|all>] [--offline]
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";
import { parseArgs } from "node:util";
import { collect, FIRST_SEASON, LAST_SEASON } from "../lib/pwa/collect.mjs";
import { createCrawler } from "../lib/pwa/crawl.mjs";
import { tourFiles } from "../lib/pwa/files.mjs";
import { assignPseudonyms } from "../lib/pwa/pseudonym.mjs";
import { BAR, buildRatings, CHECK_SEASONS } from "../lib/pwa/ratings.mjs";
import { possibleDuplicates, resolveEvents } from "../lib/pwa/riders.mjs";

// Everything from raw events to the files, without the network or the disk.
export function buildTour(rawEvents, { aliases = {}, fixes = {} } = {}) {
  const { events, riders, unmatched } = resolveEvents(rawEvents, aliases);
  const pseudonyms = assignPseudonyms(riders, fixes);
  const ratings = buildRatings(events);
  const files = tourFiles({ events, riders, pseudonyms, ratings });
  return { files, events, riders, unmatched, duplicates: possibleDuplicates(events, riders), ratings };
}

const percent = (share) => `${(share * 100).toFixed(1)}%`;

export function summarize({ events, unmatched, duplicates, ratings }, notes) {
  const lines = ["Season  events  entries  ladder heats"];
  const seasons = [...new Set(events.map((e) => e.season))];
  let sailors = 0;
  for (const season of seasons) {
    const divisions = events.filter((e) => e.season === season).flatMap((e) => Object.values(e.divisions));
    const heats = divisions.flatMap((d) => d.ladders.flatMap((l) => l.rounds.flat()));
    sailors += heats.reduce((sum, h) => sum + h.riders.length, 0);
    lines.push(`${season}    ${String(events.filter((e) => e.season === season).length).padStart(6)}  ${String(divisions.reduce((sum, d) => sum + d.entries.length, 0)).padStart(7)}  ${String(heats.length).padStart(12)}`);
  }
  const noLadder = events.filter((e) => e.season >= 2014).flatMap((e) => Object.entries(e.divisions).filter(([, d]) => !d.ladders.length).map(([name]) => `${e.name}: ${name}`));
  lines.push("", `Divisions from 2014 on without a freestyle ladder (${noLadder.length}):`, ...noLadder.map((n) => `  ${n}`));
  lines.push("", `Notes (${notes.length}):`, ...notes.map((n) => `  ${n}`));
  lines.push("", `Unmatched ladder sailors: ${unmatched.length} of ${sailors} (${percent(unmatched.length / Math.max(sailors, 1))})`, ...unmatched.map((u) => `  event ${u.event} ${u.division} heat ${u.heat}: ${u.surname} ${u.sailNumber}`));
  lines.push("", `Possible duplicates (${duplicates.length}):`, ...duplicates.map((d) => `  ${d.a} / ${d.b}: ${d.reason}`));
  const { settings, check } = ratings;
  lines.push("", `Ratings: tau ${settings.tau}, newcomers ${settings.newcomerRating}, placings worth ${settings.placingsWeight} heats`);
  lines.push(`Check on ${CHECK_SEASONS.join("–")}: favourite won ${percent(check.hitRate)} of ${check.heats} heats, log loss ${check.logLoss} (bar ${percent(BAR)})`);
  return lines.join("\n");
}

const readJson = (file) => (existsSync(file) ? JSON.parse(readFileSync(file, "utf8")) : {});

async function main() {
  const { values } = parseArgs({ options: { refresh: { type: "string" }, offline: { type: "boolean", default: false } } });
  if (values.refresh !== undefined && values.offline) throw new Error("--refresh and --offline can't be used together");
  const refresh = values.refresh === undefined ? null : values.refresh === "all" ? "all" : Number(values.refresh);
  if (Number.isNaN(refresh)) throw new Error(`--refresh takes a season or "all", not "${values.refresh}"`);
  const root = fileURLToPath(new URL("..", import.meta.url));
  const tour = join(root, "tour");
  const crawler = createCrawler({ cacheDir: join(root, "cache", "pwa"), offline: values.offline });
  const seasons = Array.from({ length: LAST_SEASON - FIRST_SEASON + 1 }, (_, i) => FIRST_SEASON + i);
  const { events, notes } = await collect(crawler, { seasons, refresh, log: (line) => console.log(line) });
  const built = buildTour(events, { aliases: readJson(join(tour, "aliases.json")), fixes: readJson(join(tour, "pseudonyms.json")) });
  console.log(`\n${summarize(built, notes)}\n`);
  if (built.ratings.check.hitRate < BAR) {
    throw new Error(`The favourite won ${percent(built.ratings.check.hitRate)} of ${CHECK_SEASONS.join("–")} heats, below the ${percent(BAR)} bar. Nothing was written.`);
  }
  for (const [path, text] of Object.entries(built.files)) {
    const out = join(tour, path);
    mkdirSync(dirname(out), { recursive: true });
    writeFileSync(out, text);
  }
  for (const name of ["aliases.json", "pseudonyms.json"]) if (!existsSync(join(tour, name))) writeFileSync(join(tour, name), "{}\n");
  console.log(`Wrote ${Object.keys(built.files).length} files to tour/ (${crawler.downloads} pages downloaded)`);
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  main().catch((error) => {
    console.error(error.message);
    process.exit(1);
  });
}
```

```js
import { test } from "node:test";
import assert from "node:assert/strict";
import { readdirSync, readFileSync } from "node:fs";
import { BAR } from "../lib/pwa/ratings.mjs";
import { nameKey } from "../lib/pwa/riders.mjs";

// Checks the committed data in tour/, as built by npm run tour-data.
const tour = new URL("../tour/", import.meta.url);
const read = (path) => JSON.parse(readFileSync(new URL(path, tour), "utf8"));
const riders = read("riders.json");
const ratings = read("ratings.json");
const events = readdirSync(new URL("seasons/", tour)).flatMap((file) => read(`seasons/${file}`).events);

test("rider ids and pseudonyms are unique, and no pseudonym is a real name", () => {
  const ids = riders.map((r) => r.id);
  assert.equal(new Set(ids).size, ids.length);
  const pseudonyms = riders.map((r) => nameKey(r.pseudonym));
  assert.equal(new Set(pseudonyms).size, pseudonyms.length);
  const realNames = new Set(riders.map((r) => nameKey(r.name)));
  assert.deepEqual(riders.filter((r) => realNames.has(nameKey(r.pseudonym))).map((r) => r.id), []);
});

test("Balz Müller is Balt Möller", () => {
  assert.equal(riders.find((r) => r.id === "m:balz-muller")?.pseudonym, "Balt Möller");
});

test("every entry's rider is in riders.json and has a rating going into the event", () => {
  const known = new Set(riders.map((r) => r.id));
  const missing = [];
  for (const event of events) {
    for (const [division, { entries }] of Object.entries(event.divisions)) {
      for (const { rider } of entries) if (!known.has(rider) || !ratings.events[event.id]?.[division]?.[rider]) missing.push(`${event.id} ${rider}`);
    }
  }
  assert.deepEqual(missing, []);
});

test("at most 1% of ladder sailors are unmatched", () => {
  const sailors = events.flatMap((e) => Object.values(e.divisions).flatMap((d) => d.ladders.flatMap((l) => l.rounds.flat().flatMap((h) => h.riders))));
  const unmatched = sailors.filter((s) => typeof s !== "string");
  assert.ok(sailors.length > 0, "there are ladder sailors");
  assert.ok(unmatched.length <= sailors.length * 0.01, `${unmatched.length} of ${sailors.length} ladder sailors are unmatched`);
});

test("the favourite won at least 65% of the 2022-2026 ladder heats", () => {
  assert.ok(ratings.check.heats > 0, "there are heats to check");
  assert.ok(ratings.check.hitRate >= BAR, `the favourite won ${ratings.check.hitRate}`);
});
```
